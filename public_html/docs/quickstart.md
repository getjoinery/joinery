# Quick Start: Your First Joinery Site

The step-by-step walkthrough for a first site — renting a server, pointing a domain at it, and installing Joinery from a web browser with nothing to type at a command line — lives on getjoinery.com:

**[https://getjoinery.com/page/quickstart](https://getjoinery.com/page/quickstart)**

Already own the domain you want to use? Take the alternate quick start, which reads what your domain does today and shows the steps as they apply to it:

**[https://getjoinery.com/page/quickstart-existing-domain](https://getjoinery.com/page/quickstart-existing-domain)**

If you are comfortable at a command line, or already have a server to install on, the [installation reference](installation.md) covers manual installs, Docker, multi-site setups, and every option in detail.
