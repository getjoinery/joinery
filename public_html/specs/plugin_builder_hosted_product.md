# Hosted Plugin Builder Product

## Concept

Sell hosted Joinery instances as a plugin-building platform rather than a full membership/event product. The customer gets a live Joinery environment pre-configured with a "Plugin Builder" plugin that lets them design, develop, and export Joinery plugins — without needing to run their own server or understand the underlying platform.

## Core Idea

- The hosted instance IS the product (not a demo or trial)
- The Plugin Builder plugin is the primary value proposition
- Customers build and export plugins they can sell or deploy elsewhere
- Joinery platform capabilities are exposed as building blocks

## Open Questions

- What does "export" look like — zip download, GitHub push, marketplace listing?
- Is the target audience developers, no-coders, or both?
- How does plugin isolation work — each customer gets their own instance, or multi-tenant with sandboxing?
- What's the pricing model — subscription per instance, per plugin exported, marketplace rev-share?
- Does the Plugin Builder plugin itself need to exist first, or is the spec about building it?
- What's the relationship between this and the existing plugin system?
