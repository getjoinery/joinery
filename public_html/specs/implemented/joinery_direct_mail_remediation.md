# Joinery Direct — Post-Build Review Remediation

**Status:** COMPLETE (2026-08-12) — every finding is RESOLVED or consciously
ACCEPTED. The multi-agent code review of the built feature produced 5 architecture
items and 19 bugs; all are fixed with tests, and the small set of residuals below
are accepted decisions (won't-fix, or deferred pending a specific future trigger),
each with its reasoning recorded here rather than left as a live TODO. Companion to
`implemented/joinery_direct_mail_review.md` (the pre-build F/G/H passes).

**Legend:** `Arch` = the design is wrong, not just the code (these are the ones
that ripple). `Bug` = localized fix. Sev = Critical/High/Medium/Low.

## Status roll-up

All architecture items (A1–A5) and all 19 bug items (B1–B19) are **RESOLVED**. Of the residuals, **A1-g1 (High), A1-g2, and B9-g1 are RESOLVED too** (relay gate-at-commit for unencrypted mailboxes + identity on the row; Go→PHP signature direction added to the wire gate; Direct-message forward MIME synthesis) — all with tests. The remaining four are **ACCEPTED** — conscious final decisions, not open work, none blocking and none a regression:

- **A4-g1** (Med): the tracker's own "charge-only `.meta`" prescription is a REGRESSION (it makes decoys fill their cap while pull-drained real addresses don't — a *clearer* oracle); the correct fix (forward decoys to the box for held-charge parity) is a real design change deferred deliberately.
- **A4-g2** (Low): a sub-µs decoy scalarmult, 3+ orders of magnitude under the shared per-request DB/crypto noise floor — unmeasurable.
- **A5-g1** (Low): true structural parity needs codegen; both drifting surfaces are gate-enforced today (byte-diff both directions; `TestIsPublicIPMatchesThePlatformTable`).
- **B15-g1** (Low): the per-instance rate limit already bounds live Direct; a proper tier-aware plugin preflight hook is deferred rather than a per-preflight COUNT.

`joinery_direct_enabled` remains 0.

## Confirmed sound (do not touch)

Send-side placement & retry-queue narrowing; CC/BCC refusal; `storeDirectMessage`
transaction/dedup parity; deferred-decline files rather than bounces; decoy is a
genuine prime-order curve point with byte-exact PHP/Go derivation; nonce TTL ≥
freshness window; session redeem + nonce claim atomic; `sealedSizeCeiling`
byte-identical; `SafeHttpClient` pins to validated IP set; `DirectStats` interval
is a real int cast; spool reclamation of abandoned preflights; compose indicator
session-gated + rate-limited; relay holds no signing key.
