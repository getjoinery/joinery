About Joinery

An independent, source-available web framework built by one developer over 15 years. No investors. No framework underneath. No mystery layers.

The project

Joinery is a PHP application framework that ships with the plumbing already done — auth, sessions, payments, email, REST API, admin dashboard, plugin system, and theme engine. It's the foundation ScrollDaddy is built on, and the foundation you can build your next project on.

The source is available. You can read every line. You can self-host it on your own infrastructure. You can export all your data at any time. No lock-in, no data harvesting, no platform fees.

It runs on PHP and PostgreSQL — a proven, well-understood stack. No Node build step required. No framework underneath. Direct, readable code.

The creator

Joinery is built and maintained by Jeremy Tunnell — a software developer who has been building and refining this codebase for 15 years.

Being a solo developer is a feature, not a bug. It means opinionated design, fast iteration, and no design-by-committee. Every feature exists because it solves a real problem. Every line of code has a clear owner and a clear purpose.

The goal is to build something sustainable and lasting — software that developers can rely on for years, not a startup looking for an exit.

Why a solo developer?

Most software companies raise venture capital, hire fast, and optimize for growth metrics. This creates misaligned incentives — the company needs to maximize revenue, which means maximizing what they extract from customers.

Joinery has no investors to satisfy. No board of directors. No growth targets. Every decision can be made in the interest of the people who actually use the software.

It also means the codebase stays coherent. One developer means one vision, one architectural style, and zero "we inherited this from the team that left." You're not debugging someone else's decisions about someone else's decisions.
